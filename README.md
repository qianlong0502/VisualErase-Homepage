# VisualErase-Homepage

VisualErase 论文的独立静态项目主页。参考 TINA-Plus-Homepage 的暖白、蓝绿、珊瑚色视觉风格，默认英文，支持中文切换与移动端布局。

## 内容与维护

- `index.html`：核心思想、完整论文摘要及中文译文、方法、交互结果表与定性对比。
- `styles.css`：响应式样式、键盘焦点与减少动画偏好。
- `script.js`：中英文切换、语言偏好存储、三类任务完整主表。
- `media/`：由正式手稿 PDF 图导出的独立 PNG 与 SVG favicon，不依赖仓库外路径。
- `.github/workflows/pages.yml`：沿用 TINA+ 的 GitHub Pages 工作流。

内容以 [`../latex/main.tex`](../latex/main.tex) 为准，当前对应 2026-10-04 手稿。表格保持正文的一位小数口径，包含所有任务可用基线，身份结果保留未修正 GCD 数值，裸体采用冻结的语义可辨识性评估协议。无 JavaScript 时保留风格任务的 SD1.4 / STEREO / VisualErase 摘要表。

主页术语与结论以论文正文为准，不引入内部评测代号。结果表下简要突出各任务发现与评估器，详细诊断留在论文中。章节参考 TINA+ 使用独立珊瑚色编号、大字号标题与更宽的标题间距，并提供对应中文标题。

视觉层级：章节编号为 48–72px 珊瑚色数字；方法内步骤采用小号蓝绿描边标签（STEP / 步骤），避免与章节混淆。首页引导语为 18–24px，结论标签为 24–32px，随屏幕宽度调整。

三张论文配图的图注统一使用 16–18px 字号和 1.75 行高，以保持说明文字可读。

完整摘要位于首页指标及说明下方，使用默认折叠的原生 details 卡片，标题、阅读提示及加减号展示展开状态；支持键盘操作与中英文切换。

配图来源：`fig-intro.pdf`、`fig-method.pdf`、`fig-visual.pdf`。PNG 分别导出为最长边 2200、2200、2400 像素。后续论文图更新时需同步导出，定性图保留原稿展示遮罩。无需 npm、构建工具、外部字体或 CDN。

论文仍为匿名稿，主页保留 Anonymous Authors。论文与代码尚无已确认公开链接，当前以静态“待公开”状态展示，未添加虚构作者、出版信息或 BibTeX。正式公开时更新作者、资源链接与必要分享元数据。

## 预览与发布

可直接用浏览器打开 `index.html`。也可由用户在本目录运行：

```bash
python3 -m http.server 8000
```

再访问 `http://localhost:8000`。已按用户要求启动 8000 端口预览服务，尚未执行浏览器自动化验证。

发布到 GitHub Pages 时，在该独立仓库的 Settings → Pages 中选择 GitHub Actions，之后推送 `main` 会触发部署。此目录属于 `_Draft/` 下的独立仓库，不纳入主科研仓库；本次未提交、推送或发布。
